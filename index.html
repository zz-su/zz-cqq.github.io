开启双人实时同步

需要一个免费的 Firebase 项目。配置一次后，两部手机输入相同房间码即可共享打卡和回忆。

配置步骤：① 在 Firebase Console 创建项目；② 添加 Web 应用并复制配置；③ 启用 Authentication 的匿名登录；④ 创建 Realtime Database；⑤ 将数据库规则设为仅登录用户可读写（示例见随附说明）。此版本通过匿名登录连接数据库。
